# Cinematch

**Find your next favorite movie.**

Cinematch is a movie recommendation website designed to help users discover movies based on their interests and preferences.

## Features

- Browse and discover movies
- Search for movies
- Explore personalized movie recommendations
- Save movies to a watchlist
- Discover your movie taste with Taste DNA
- User profiles and account features

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Movie Data:** TMDB API, where configured

## Getting Started

### Prerequisites

- Node.js and npm
- MongoDB connection, if required by the backend
- TMDB API key, if required by the movie-data features

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/lipiroy558-cloud/Cinematch.git
   cd Cinematch
   ```

2. Install frontend dependencies:

   ```bash
   npm install
   ```

3. Configure your environment variables using `.env.example`. Replace the placeholder values with your local credentials.

4. Start the frontend:

   ```bash
   npm run dev
   ```

5. Start the backend separately using its own setup instructions and environment configuration.

## Environment Variables

Keep your real `.env` files private. Use `.env.example` to document the required variable names with placeholder values only.
